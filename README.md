# Архив Яндекс Почты

Скачивает **все письма** с корпоративных ящиков Яндекс Почты / Яндекс 360 и складывает их на компьютер в виде архива, который можно открыть в браузере.

Один и тот же пароль можно задать на все ящики: скрипт просто пройдёт по списку адресов и заберёт почту из каждого.

## Что получится

После запуска появится папка `mail-archive/`:

- `index.html` — список всех ящиков
- внутри каждого ящика — папки как на сервере (Входящие, Отправленные и т.д.)
- каждое письмо в двух видах:
  - `.html` — открывается в Chrome / Edge / Firefox, есть поиск по теме и отправителю
  - `.eml` — исходное письмо, открывается в Outlook, Thunderbird, «Почте» Windows
- вложения лежат рядом с письмом
- `folder.mbox` — общий файл папки, его можно импортировать в Thunderbird

Письма на сервере **не удаляются**. Непрочитанные остаются непрочитанными.

Повторный запуск докачивает только новые письма.

## Подготовка ящиков

Для Яндекс 360 (корпоративная почта) логин — **полный адрес**, например `ivan@company.ru`.

На каждом ящике (или сразу для организации) нужно разрешить IMAP:

1. Откройте [настройки почтовых программ](https://mail.yandex.ru/?dpda=yes#setup/client).
2. Включите **«С сервера imap.yandex.ru по протоколу IMAP»**.
3. Оставьте включённым пункт про пароли приложений / OAuth.

Если обычный пароль Яндекс не принимает (часто так и бывает), создайте [пароль приложения](https://passport.yandex.ru/security/app-passwords) типа **«Почта»**. Его можно поставить одинаковым сценарием на все ящики, либо указать один общий пароль приложения, если вы так настроите доступ.

IMAP-сервер: `imap.yandex.ru`, порт `993`, SSL.

## Как запустить

Нужен Python 3.10 или новее, дополнительные пакеты не нужны.

```bash
cp mailboxes.example.txt mailboxes.txt
```

Впишите адреса, по одному на строку:

```
buh@company.ru
director@company.ru
info@company.ru
```

Дальше один из вариантов.

Интерактивно (пароль спросит сам):

```bash
python3 archive_mail.py --mailboxes mailboxes.txt --output mail-archive
```

Или через переменную окружения:

```bash
export YANDEX_MAIL_PASSWORD='ваш_пароль'
python3 archive_mail.py
```

Или из файла, который **нельзя** коммитить в git:

```bash
python3 archive_mail.py --password-file /path/to/password.txt
```

Проверка на паре писем:

```bash
python3 archive_mail.py --limit 5
```

Когда закончит — откройте `mail-archive/index.html`.

Если вы не в России и `imap.yandex.ru` не открывается:

```bash
python3 archive_mail.py --host imap.yandex.com
```

## Важно

- Пароль и `mailboxes.txt` в репозиторий не кладите. В `.gitignore` это уже учтено.
- Архив может быть большим: каждое письмо хранится целиком, плюс вложения.
- Если Яндекс обрывает соединение, скрипт сам переподключается и продолжает.
- Этот инструмент только читает почту. Он не меняет пароли, не удаляет письма и не настраивает ящики за вас.
